# Rubik's Cube Solver and Helper

This program will help you solve your Rubik's cube, but not in the way that solvers traditionally do. This solver will help you actually improve your solves, finding the optimal solving sequence and comparing it with your own solution each step of the way.

## Where is the project at right now?

This project is currently in active development, and is in its early stages. Currently the base solver has been more or less completed, and is able to find solutions for different steps if there are any, using only select moves.

## What's next?

The next step for this project is to actually implement solvers for specific steps in the different solving methods that people use, such as Roux and CFOP. As a Roux main myself, I will be likely starting with this method and will iron things out as I make a solver for first block.

I am also in the process of developing a GUI.

## How has it been developed?

I have mostly coded the logic myself, aside from using Claude to brainstorm the structure of the cube data and how moves would be applied to the data. The GUI has been fully vibecoded using Claude.
